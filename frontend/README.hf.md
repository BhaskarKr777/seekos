# SeekOS Frontend

Next.js 16 search UI for SeekOS — privacy-focused, open-source search platform.

## Build-time Variables (set as Space Variables, NOT Secrets)

| Variable | Description | Example |
|---|---|---|
| `NEXT_PUBLIC_API_BASE_URL` | URL of your SeekOS API Space | `https://your-username-seekos-api.hf.space` |
